# Portfolio — Joseph Ducret

Ce dépôt contient le code source de mon portfolio personnel. Il présente mon parcours, mes projets et les compétences que je développe dans le cadre de ma reconversion vers le développement web.

## Site en ligne

[Consulter le portfolio](https://portfolio-joseph-ducret.vercel.app/)

## Fonctionnalités

* Mise en page responsive pour ordinateur et mobile
* Navigation fixe avec accès aux différentes sections
* Présentation des projets, des technologies utilisées et des sites publiés
* Présentation du parcours professionnel
* Liens directs vers l’adresse e-mail et le profil GitHub
* Page de mentions légales

## Technologies et outils

* HTML5
* CSS3
* Git et GitHub
* Vercel
* Polices hébergées localement

## Structure du projet

```text
portfolio-joseph-ducret/
├── assets/
│   ├── font/
│   └── images/
├── index.html
├── mentions-legales.html
├── style.css
└── README.md
```

## Affichage local

Le site étant entièrement statique, il peut être consulté en ouvrant `index.html` dans un navigateur ou en utilisant l’extension Live Server dans VS Code.

## Déploiement

Le site est déployé sur Vercel depuis la branche `main` du dépôt GitHub.
